# 三种模式的契约（改古法编程前必读）

古法编程只允许存在三种状态，判断**只认 DOM 标记**，不要用 localStorage / 内存状态对象：

| 模式 | 标记 | 说明 |
|---|---|---|
| 经典模式 | 无标记 | DSH 原生界面，古法插件只保留工作区菜单入口 |
| 古法编程 | `html[data-gufa-ide]` | IDE 覆盖层；工作区、会话、编辑器、Git、终端全部按下面「功能锁」工作 |
| 摸鱼模式 | `html[data-gufa-ide][data-gufa-float]` | 独立悬浮窗实例；由 helper 注入，**只影响悬浮窗，绝不反向影响主窗口** |

判断函数：`G.isFloatMode()`（唯一允许的摸鱼判断方式）。

## 功能锁（古法编程模式必须始终成立，改动后逐项自查）

1. 从哪个工作区的「…」菜单点「古法编程」，IDE 就打开哪个工作区（入口工作区优先，不先恢复上次项目）。
2. 若经典模式当前会话属于该工作区：不切换会话，只对齐项目根。
3. 若不属于：切到该工作区最近的会话，再打开项目根。
4. 进入 IDE 后：项目文件树、已打开标签、Git 状态、终端、右侧官方会话都可用。
5. 退出 IDE（返回经典模式）后：经典界面恢复原样，不残留 `data-gufa-*` 标记。
6. 摸鱼逻辑（状态注入、悬浮层、吸附、`G.floatState`、`G.isFloatMode()` 分支）**只能**在 `data-gufa-float` 下生效。

## 摸鱼模式交互（v1.3.11 起）

- IDE 标题栏「摸鱼」按钮（带框两字）→ 选择要吸附的 App → 悬浮窗出现并吸附该窗口，**DSH 主窗口被隐藏（⌘H 效果）**；
- 悬浮窗标题栏：透明度滑块（20%–100%，持久化）、**退出摸鱼**按钮（占原「返回经典模式」位置，摸鱼里不再显示返回经典模式）；
- 摸鱼里不显示皮肤（梁圣）背景；
- **透明度一致性**：摸鱼窗口只保留「覆盖层根节点」一层半透明底（`rgba(13,15,19,var(--gufa-float-alpha))`），
  编辑器、资源管理器、会话框、终端面板内部全部透明 → 所有区域看到的透明度完全一致，随滑块整体变化。
  注意官方停靠会话的 `.gufa-dock-toolbar` / `.gufa-dock-host` 也自带底色，摸鱼里必须一并设为透明，
  否则会话框会叠两层（看起来发灰/更实）。
- **固定吸附**：吸附模式下悬浮窗只留在「被跟随 App 所在的 Space/屏幕」，用户切换 Space/滑屏时不会跟着跑到当前屏；
  只有「自由悬浮（不吸附）」模式才允许出现在所有 Space。
- 退出摸鱼：悬浮窗把「项目 / 打开的标签页 / UI 布局 / 当前会话」写回 Host，然后优雅退出并恢复显示主窗口；
  主窗口重新获得焦点时自动取回并应用这些状态（项目 → 标签页 → 会话）。

## 摸鱼模式跨平台实现

- helper 与 Host 的通信协议统一在 `desktop/float/PLATFORM-PROTOCOL.md`（argv JSON + controlPath 控制文件 + ciProbe 冒烟）。
- macOS：`desktop/float/GufaFloat.m`（已可用，universal arm64+x86_64）；Windows：`desktop/float/win/`（Win32 + WebView2，首版不透明）；Linux：`desktop/float/linux/`（X11 + GTK3/WebKit2GTK，仅 X11）。
- 后两者由 `.github/workflows/build-float.yml` 在 CI 编译 + ciProbe 冒烟，产物放到 `desktop/float/bin/{win-x64,linux-x64}/` 随 npm 包发布；真机交互仍在验收。
- Host 端 `host/dev.js` 的 `float.*` API 已按平台分支：darwin 用 .app + AX；win32/linux 用原生 helper + controlPath 退出，用 PowerShell/wmctrl 列窗口。

## 摸鱼模式现行限制

- 只在独立悬浮窗实例里生效；主窗口永远走古法编程模式；
- **状态快照语义（定案）**：
  - 点「摸鱼」= 对主窗口当前状态拍快照（工作区项目、打开的标签页、当前文件、视图/终端等面板状态、当前会话），摸鱼窗口按该快照原样展示；
  - 点「退出摸鱼」= 对摸鱼窗口当前状态拍快照（同上），写回 Host，主窗口恢复显示时**按该快照原样恢复**（覆盖主窗口被隐藏前的状态）；
  - 两侧快照互不串扰：恢复时必须用「重渲染后的最新 openFile/applyProject」，不能用 await 之前的旧闭包（旧闭包里 project 可能还是 null，会导致文件打不开）。
